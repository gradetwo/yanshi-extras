# assets · Assets

**English** | [简体中文](README.zh-CN.md)

Brushes, textures, paper surfaces, sample images and other assets. One subdirectory per asset category.

- Large files are stored with Git LFS: run `git lfs install` before cloning, otherwise you will only get pointer files.
- Every asset must state its source and license; do not add anything whose source or license is unclear.
